# 书旅Map · 校园二手书循环平台 MVP

基于商业计划书实现的中文响应式网页应用，原生 HTML/CSS/JavaScript，零依赖。全部账号、点位、距离、库存与群聊为示例。

## 运行

解压后双击 `dist/index.html` 即可体验。推荐安装 Node.js 后，在项目目录执行：

```sh
node server.cjs
```

打开 http://127.0.0.1:4174 。按 Ctrl+C 停止。无需 npm 安装。核心业务测试：`node tests.cjs`。如已安装 npm，也可用 `npm start` / `npm test`。

## 已实现

1. 地图寻书：虚构校园交互示意图，切换三处书柜、查看营业状态、柜内库存与空余投递格；按书名/作者搜索、按主题与书柜筛选。
2. 借阅和购书：14 天借期、10 书币押币、最多同时借3本、书币购书、模拟取书凭证、归还退币；借走后从可用库存移除，归还后恢复。
3. 回收：模拟扫描填充书籍信息，手动核对品相和书柜、提交待质检；个人中心提供明确标注的模拟后台，审批通过后发币并上架，拒绝则保留取回提示。
4. 盲盒：主题候选书与概率披露、确认扣书币、随机揭晓、记录领取码；余额不足不能兑换。
5. 书币：实时余额、收支流水。押币、回收奖励和盲盒消费联动。
6. 社群：加入/退出三个兴趣小组、本地讨论消息、刷新后保留。
7. 个人中心：在借/已兑换/已归还书架、投递进度、备份导入导出、重置演示。

## 演示与真实服务的边界

- 这是可交互的单机 MVP，无注册、后端数据库和跨设备同步；数据存在浏览器 localStorage。清理站点数据会丢失记录，请导出备份。
- 示意地图不是实际地理地图；距离固定，不请求地理位置；未接入 LBS、真实柜体、开柜二维码、OCR、消毒、称重、信用平台和支付。
- 取书码无开柜能力；群消息不发送到其他人。信誉值与阅读标签为静态示例，没有推荐算法。
- 商业计划的现金回收、混合支付、优惠券、广告系统与数字产品分成留待后续，演示只走书币闭环。
- 书币无现金价值。全新35、九成新25、八五新15；审核一次发放一次。超期每日扣1押币，最多扣10，不产生额外现金债务。
- 质检审批入口仅为课堂演示，真实上线必须移到运营权限下。导入仅用于自己导出的备份，导入与重置会覆盖本机数据。
- 随机盲盒来自单独的示例主题书池，未模拟实物逐本库存，也未覆盖售后与未领取超时；不可用于真实经营。

## 文件

`dist/core.js`：模型、业务规则与校验；`dist/app.js`：界面交互和存储；`dist/style.css`：响应式样式；`dist/index.html`：入口；`tests.cjs`：业务规则测试；`server.cjs`：本地服务器。详见 `产品与演示说明.md`。
